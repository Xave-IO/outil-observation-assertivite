# outil-observation-assertivite
Cet outil a été développé pour servir de référentiel et de support d'observation de mises en situation dans le cadre de jeux de rôles où l'assertivité est le comportement cible à adopter. L'observé peut ainsi repartir avec un support visuel et travailler à partir de ses points forts et axes d'amélioration identifiés.
